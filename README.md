# LENA · Estudio creativo

Sitio web y catálogo de LENA: diseño gráfico, identidad visual y productos personalizados, con carrito que arma el pedido y lo envía por WhatsApp.

📖 **Toda la documentación está en [LEEME.md](./LEEME.md)**: cómo editar productos, fotos y precios, cómo ejecutarlo en Windows y cómo publicarlo en Vercel.

```bash
npm install     # instalar dependencias (solo la primera vez)
npm run dev     # ver el sitio en http://localhost:5173
npm test        # probar la lógica del carrito
npm run build   # generar la versión para publicar (carpeta dist)
```
